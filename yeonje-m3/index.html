so that — 목적

  • took ~ so that they can → could눌러서 펼쳐 보세요

    Tom studied hard so that he can pass the test.

    Tom studied hard so that he could pass the test.

    주절이 과거(studied)이므로 so that 뒤에도 could 를 씁니다.

  • could passed → could pass

    Tom studied hard so that he could pass the test.

    could 뒤에는 동사원형을 씁니다.

  • so + 형용사 + that 은 결과(너무 ~해서)

6과 · 문법 ②

형용사 · 부사 + enough to

형용사 / 부사 + enough to + 동사원형

= so + 형용사 + that + 주어 + can

  • 1회 중 0회 아래는 다른 문법으로 낸 꼴
  • 올해 1학기 중간 서답형 1 · 4점 우리말 영작
  • 올해 1학기 중간 8번 · 3점 밑줄 어법 고르기
함정 3개
  • enough strong → strong enough눌러서 펼쳐 보세요

    Leo is enough tall to reach the shelf.

    Leo is tall enough to reach the shelf.

    enough 는 형용사 뒤에 씁니다.

  • that ~ can't 는 too ~ to — enough to

    The soup was so hot that I couldn't eat it. = The soup was too hot for me to eat.

  • 주어가 다르면 for + 목적격 + to ~

    The box was light enough for me to carry.
