6과 · 문법 ①

so ~ that — 너무 ~해서 …하다

so + 형용사·부사 + that + 주어 + 동사

He studied so hard that he was able …본문

과거 이야기면 that 뒤도 과거

I was so tired that I went to bed early.

that 뒤바꿔 쓰기예
can'ttoo ~ totoo hot to eat
can~ enough totall enough to reach
  • 올해 1학기 중간 서답형 3 · 8점 우리말 영작 2문장
  • 작년 2학기 기말 19번 · 3점 어법상 옳은 문장
함정 2개
  • so tired that I go → went눌러서 펼쳐 보세요

    Ben was so sleepy that he skipped dinner.

  • so that + 주어 + can = ~하도록

    Tom studied hard so that he could pass the test.

    '~하도록·~하기 위해'로 해석되면 목적 so that, '너무 ~해서 …하다'로 해석되면 결과 so ~ that 입니다.

6과 · 문법 ②

지각동사 + 목적어 + -ing · 동사원형

see · hear + 목적어 + -ing

… heard people shouting …본문

동사원형도 쓸 수 있음

We saw a man take pictures.

목적어 뒤예
-ing · 동사원형 saw him running
to부정사 saw him to run
과거형 · -s saw him ran
  • 작년 2학기 기말 9번 · 4점 빈칸에 알맞은 꼴
함정 2개
  • hear him to sing → sing(ing)눌러서 펼쳐 보세요

    I saw Leo to cross the road.

    I saw Leo cross the road.

    지각동사 + 목적어 뒤에는 to 를 쓰지 않습니다.

  • want · tell 은 목적어 뒤 to ~

    Mom wants me to clean my room.

    My dad told me wear a helmet.

    My dad told me to wear a helmet.

    tell + 사람 뒤 동작에는 to 를 붙입니다.
