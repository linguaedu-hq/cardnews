It + be동사 + 형용사 + to + 동사원형

의문문: Is it + 형용사 + to ~?

형용사to 앞 의미상 주어
일이 어떤지 (easy · hard · important)for + 목적격

의미상 주어의 형태목적격 (us)
  • 올해 1학기 중간 8번 · 4점 to부정사 쓰임이 같은 것 모두

  • It is fun learn → to learn눌러서 펼쳐 보세요

    It is fun to learn new songs.

  • It is cold. 의 It 은 가주어 (날씨)

    It is too cold to go out.

    It 은 날씨·시간·거리를 말하는 비인칭 주어(해석하지 않는 it)라 가주어가 아닙니다.

  • important for we → for us

    It is important for we to drink water.

    It is important for us to drink water.

    의미상 주어는 목적격으로 씁니다.
