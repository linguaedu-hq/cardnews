부탁하기

Can you please fix my bike?

Sure. No problem.

거절하기

I'm sorry, but I can't.

함정 2개

6과 · 문법 ①

접속사 that

think · hear · learn + that + 주어 + 동사

We know that plastic is bad.

목적어 that 은 생략할 수 있음

I think the box is too heavy.

지시어 that + 명사 = 저 ~

I think that cup is reusable.

that 바로 뒤 is = 지시어(그것)

Don't you think that's cool?본문

작년 시험
  • 예상 틀린 곳 골라 고쳐 쓰기 — 작년 서답형 8 꼴
함정 3개
  • that 뒤에 주어 + 동사눌러서 펼쳐 보세요

    I think that Emma is kind.

    접속사 that 뒤에는 완전한 문장이 옵니다.

  • that's cool 의 that = 그것

    I think that is Tom's.

    앞에 꾸밈을 받는 명사가 없고 that 바로 뒤가 is·was 같은 동사면 that 은 '저것은, 그것은'이라는 지시어입니다

  • that + 복수 명사 → those
6과 · 문법 ②

to부정사 명사적 용법

목적어: want · decide + to + 동사원형

I decided to fix it and reuse it.본문

주어: To + 동사원형 ~ + is

보어: be동사 + to + 동사원형

My goal is to use less plastic.

부정: not + to + 동사원형

I decided not to buy a new bag.
